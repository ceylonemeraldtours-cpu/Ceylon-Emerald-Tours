# Tour photos

For each tour id in `src/data/toursData.ts`, add a folder with a cover and five gallery photos:

    public/images/tours/<tour-id>/cover.jpg   (used on cards, about 1200 x 900)
    public/images/tours/<tour-id>/1.jpg ... 5.jpg   (used in the detail-page collage; 1.jpg is the large tile)

Tour ids: 4-day-cultural-wildlife, 7-day-cultural-natural-wonders, 9-day-grand-tour,
14-day-ultimate-escape, galle-one-day, colombo-one-day, ella-one-day, polonnaruwa-day-tour.

Until photos exist, emerald gradients are shown. Use photos you own or have licensed.
